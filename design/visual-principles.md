# Visual Principles

Tournaments should look like a clean comparison desk: two candidates, one judgment, no decoration beyond the content itself.

## Hero Shot

- Category: product screenshot hero.
- Subject: the comparison view with two color candidates side by side, mid-tournament.
- Demo data: the sample color tournament (six named colors, Elo pairwise).
- Crop: wide desktop view, full-width comparison cards centered.
- Caption: explain that you click the candidate you prefer and the Elo ratings update live.

## Screenshot System

- Theme: light only (default theme).
- Aspect ratio: 1440 x 900 for desktop views.
- Captions should say what each image proves, not merely what it depicts.
- Never show personal paths, private tournament names, or local worktree directories.

## Social Preview

- Size: 2560 x 1280 source PNG, suitable for GitHub's 2:1 preview.
- Elements: project name, one positioning sentence, one real UI screenshot.
- Palette: Tournaments light — bg `#f4f4f4`, text `#111111`, muted `#6b6b6b`, card white `#ffffff`.
- No badges, star requests, version numbers, or decorative AI imagery.

## Motion Artifact

Defer. The comparison workflow is fast and self-explanatory from a single screenshot. A trailer adds ceremony without proving anything the hero shot does not.

## Open Publication Decisions

- Live demo: defer. Tournaments is single-user and file-backed; a hosted demo needs a sandbox mode that resets between visitors.
- Custom domain: defer. A parked domain would signal more than the project currently offers. Revisit when the project reaches stable.
- Hero choice: use the comparison screenshot, not the library or results page. The side-by-side is what makes the product click instantly.
